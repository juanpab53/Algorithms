# Algorithms – Riwi

This repository contains exercises, practical activities, and learning materials developed during the Algorithms training sessions at Riwi.

The main objective is to explore fundamental concepts and develop practical skills through hands-on exercises.

## Project Structure

The repository is organized by training sessions:

```text
Algoritmos/
│
├── sesion-01/
│   └── Exercises and activities from session 01
│
├── sesion-02/
│   └── Exercises and activities from session 02
│
│   sesion-03/
│   └── Exercises and activities from session 03
└── README.md
```

### Learning Objectives
Understand fundamental concepts of Algorithms.
Explore practical applications of Algorithms.
Develop problem-solving skills through programming exercises.
Strengthen logical thinking and computational skills.
Apply concepts learned during training sessions.
